Problem Space

Stateless models don't scale in enterprise

Naive RAG

Vector similarity floods context window. High token cost. No graph structure. Poor precision on complex queries.

No Agent Sync

Multiple agents duplicate work. No conflict resolution. Every agent starts from zero. No shared organizational memory.

Unauditable Decisions

Cannot prove reasoning path. Compliance violations go undetected. Debugging production failures becomes impossible.

AMG solution: Deterministic retrieval with graph structure, immutable audit log, and bounded evidence selection.

Technical02 / 12
Architecture

Tripartite Memory Design

CONTEXT

Per-user scope · 24–48 hour decay

  • → Recent conversations
  • → Session decisions
  • → User-specific context
  • → Stored in context tier
SEMANTIC

Shared by all agents · Cognitive weight

  • → Organizational entities
  • → Relationships & facts
  • → Bayesian confidence scores
  • → Decays: temporal + usage
AUDIT

Immutable forever · Compliance proof

  • → All operations logged
  • → Auth decisions (GRANT/DENY)
  • → Reasoning traces
  • → Never deleted/modified
Isolation principle: No cross-tier reads/writes in single transaction. Each tier is independent update domain.
Technical03 / 12
Request Flow

MindMap Pipeline: 4 Deterministic Stages

1

MINE

Extract intent & entities from user query via LLM

2

AGGREGATE

BFS on Spanner Graph with weight filters + depth bounds

3

SERIALIZE

Convert nodes/edges to structured facts with provenance

4

SYNTHESIZE

Generate response ONLY from serialized evidence

Guarantee: If evidence insufficient → pipeline returns NO_EVIDENCE. Never generates unsupported claims.

Security

Tenant Isolation & ABAC

Tenant Isolation

  • → tenant_id column on ALL tables
  • → Row-level filtering in every query
  • → Cross-tenant access impossible
  • → Immutable during record lifetime

Authorization (ABAC)

  • → Deny-by-default policy engine
  • → AuthorizationScope: agent + action + resource
  • → GRANT/DENY both audited forever
  • → Pluggable (internal or external policy)
