Architecture

MindMap: Mine → Aggregate → Serialize → Synthesize

1. MINE

Extract intent & entities from user query using LLM

2. AGGREGATE

BFS traversal with cognitive weight filters on graph

3. SERIALIZE

Convert evidence to structured payloads with provenance

4. SYNTHESIZE

Generate response ONLY from serialized evidence

Key guarantee: If evidence insufficient, pipeline fails gracefully with NO_EVIDENCE signal. Never hallucinate.

Storage

Spanner Graph Schema

9 migrations applied sequentially:

MemoryNode

id, type, payload, tenant_id, cognitive_weight, last_accessed

MemoryEdge

from_id, to_id, type, weight, confidence, metadata

AUDIT_EVENTS

Immutable: access, authorization, reasoning traces

ENGRAM_EVIDENCE

Facts grounding responses + confidence tiers

-- Sample GQL query
MATCH (n:MemoryNode {tenant_id: $tenant_id})
WHERE n.cognitive_weight > $threshold
  AND n.type IN ['ENTITY', 'RELATION']
OPTIONAL MATCH (n)-[e:IS_RELATED_TO]→(m)
WHERE e.confidence > 0.7
RETURN DISTINCT
  n.id AS entity_id,
  n.type,
  n.payload,
  COLLECT(m.id) AS related_entities,
  SUM(e.weight) AS signal_strength

Semantics

Bayesian Cognitive Weighting

LogOdds model — Each node & edge has a weight tracking relative likelihood:

weight = log(p / (1−p)) where p ∈ [0, 1]

→ Higher weight = more confident in fact
→ Lower weight = less certain, consider removing
→ Decays over time (< 30 days active use)

Weight Update Events

  • + Node used in agent response → increment
  • + Referenced in next agent call → confirmed
  • − Contradicted by new evidence → decrement
  • − Aged 30+ days unused → decay to 0.3
  • × Below threshold 0.3 → pruned

API

Four MCP Tools (HTTP Endpoints)

MEMORY_SEARCH

Find facts matching intent. Returns ranked nodes + edges with provenance.

POST /api/v1/mcp/invoke
{tool: "MEMORY_SEARCH", query: "..."}

MEMORY_ADD_FACT

Ingest new entities & relationships. Idempotent UPSERT via merkle hash.

POST /api/v1/mcp/invoke
{tool: "MEMORY_ADD_FACT", fact: {...}}

MEMORY_LOG_TRACE

Write audit events: authorization decisions, reasoning steps, errors.

POST /api/v1/mcp/invoke
{tool: "MEMORY_LOG_TRACE", event: {...}}

MEMORY_RECALL_CONTEXT

Retrieve session history + agent state. Window-based, ordered by recency.

POST /api/v1/mcp/invoke
{tool: "MEMORY_RECALL_CONTEXT", session_id: "..."}

Security

ABAC Authorization Model

Deny-by-default. Every operation requires explicit GRANT.

AuthorizationScope

  • → agent_id (which agent acts)
  • → action (search, add, trace)
  • → resource (node type, edge type)
  • → tenant_id (isolation)

Both GRANTED & DENIED events are logged to AUDIT_EVENTS. Immutable forever.

-- ABAC policy example
Rule: "agents.search_facts"
Condition:
  agent.role == "analyst"
  AND resource.type == "ENTITY"
  AND tenant_id == request.tenant_id
Effect: ALLOW

-- Every DENY is audited
Event:
  timestamp: ISO8601
  agent_id: "agent-123"
  action: "search"
  result: DENIED
  reason: "insufficient_role"
