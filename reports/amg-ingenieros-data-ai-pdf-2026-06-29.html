Storage

Cloud Spanner Graph · ISO GQL

Ejemplo: traversal de hechos semánticos con filtro de peso

-- ISO GQL — AMG semantic traversal
GRAPH agent_memory_graph
MATCH
  (n:SemanticNode {entity_name: @subject})
    -[e:HAS_FACT]->
  (f:FactNode)
WHERE
  f.weight >= 0.30           -- prune bajo umbral
  AND f.namespace = @ns  -- ABAC namespace
ORDER BY f.weight DESC
LIMIT @max_facts
RETURN
  f.fact_id, f.subject,
  f.predicate, f.object_val,
  f.weight, f.source_ids

Interleaved storage

Aristas almacenadas intercaladas en el nodo padre. Co-locality elimina round-trips en traversals profundos. P99 <5ms sin caché.

Parámetros de traversal

  • → max_facts — configurable (default 50)
  • → max_depth — acotado (default 3 hops)
  • → weight_floor — umbral de poda (0.30)

Escritura de hechos

Mutaciones Spanner. Resolución de conflictos en ingestión: hash de sujeto+predicado como clave. Marcador de tensión en colisión.

Pipeline

MindMap Pipeline — implementación

# src/pipeline/mindmap.py
class MindMapPipeline:
    async def run(
        self, request: AgentRequest
    ) -> GroundedResponse:

        # Stage 1: MINE
        anchors = await self._mine(request.prompt)

        # Stage 2: AGGREGATE (Spanner GQL)
        raw_facts = await self._aggregate(
            anchors, namespace=request.namespace
        )

        # Stage 3: SERIALIZE
        fact_payload = self._serialize(raw_facts)

        # Stage 4: SYNTHESIZE (GenAI Gateway)
        response = await self._synthesize(
            request.prompt, fact_payload
        )

        # Post-validate: every claim → fact_id
        self._validate_grounding(response)
        return response

_mine: extracción de anclas

Llamada al GenAI Gateway con prompt de extracción de entidades nombradas. Salida: list[Anchor] con tipo y texto normalizado.

_synthesize: llamada fundamentada

Prompt de sistema incluye payload de hechos + instrucción: "Cita el fact_id para cada afirmación. Si no hay evidencia, devuelve INSUFFICIENT_EVIDENCE."

_validate_grounding

Post-procesamiento: parsea respuesta, verifica que cada claim cite un fact_id existente en el payload. Lanza GroundingViolation si falla.

Weights

Cognitive Weighting — matemática e implementación

Inspirado en Engram (Harshit Kapadia, ICLR'25 workshop, 91.4% LongMemEval)

Fórmulas

W₀ = 0.5    → 62% confianza inicial

W_new = W + ln(1.25) ≈ W + 0.223  → acceso exitoso

W(t) = W₀ × e^(−λt), λ = 0.05 / hr

prune si W(t) < 0.30

# src/weights/cognitive.py
import math

WEIGHT_INIT  = 0.5
WEIGHT_DELTA = math.log(1.25)    # ≈ 0.223
DECAY_LAMBDA = 0.05              # per hour
PRUNE_FLOOR  = 0.30

def on_access(w: float) -> float:
    return w + WEIGHT_DELTA

def decay(w: float, hours: float) -> float:
    return w * math.exp(-DECAY_LAMBDA * hours)

def should_prune(w: float, hours: float) -> bool:
    return decay(w, hours) < PRUNE_FLOOR

Actualización en Spanner

Spanner DML: UPDATE semantic_nodes SET weight = @new_w WHERE fact_id = @id. No requiere transacción de lectura previa — columna atómica.

Detección de contradicciones

En ingestión: hash sha256(subject + predicate) como clave de colisión. Si ya existe un hecho con predicado diferente → inserta tension_flag=True.

Poda asíncrona

Cloud Scheduler invoca job de poda diariamente: DELETE FROM semantic_nodes WHERE computed_weight < 0.30. Sin impacto en latencia de queries.

Impacto en traversal

Filtro WHERE weight >= 0.30 en GQL reduce el payload al LLM en >30% vs. RAG sin ponderación. P99 <5ms sostenido.

Seguridad

ABAC Engine — denegación por defecto + reason codes

# src/auth/abac.py
class AbacDecision(BaseModel):
    granted: bool
    reason_code: str      # GRANT_ABAC | DENY_POLICY
    policy_id: str | None # qué política aplicó
    resource_ref: str

class AbacEngine:
    async def authorize(
        self,
        agent_id: str,
        resource_ref: str,
        action: str,
        attrs: dict[str, str],
    ) -> AbacDecision:
        # 1. Busca políticas que apliquen
        policies = await self._match_policies(
            resource_ref, action, attrs
        )
        # 2. Evalúa: primera DENY gana
        for p in policies:
            if p.effect == "DENY":
                return AbacDecision(
                    granted=False,
                    reason_code="DENY_POLICY",
                    policy_id=p.id,
                )
        # 3. Sin match → DENY por defecto
        if not policies:
            return AbacDecision(
                granted=False,
                reason_code="DENY_NO_POLICY",
            )
        return AbacDecision(granted=True, ...)

Reason codes

  • GRANT_ABAC — política permitió
  • DENY_POLICY — política explícita denegó
  • DENY_NO_POLICY — sin política = denegado
  • DENY_WEIGHT_FLOOR — hecho bajo umbral

Policy store

Policies en tabla Spanner abac_policies. Scoped por namespace + resource_pattern (glob). Recarga sin reinicio — poll cada 60s.

Delegación externa (opcional)

POST /external-authz: si configurado, llama a servicio de autorización externo (Okta FGA, Google IAM). Fallback a motor interno si timeout >200ms.

Flujo asíncrono de ingestión

1 POST /ingest → retorna job_id inmediatamente

3 Worker: chunking → NER → dedup → Spanner write
4 GET /ingest/{job_id} → status + fact_ids created

Feedback Engine → Semantic Memory

Ejemplo: test de Cognitive Weighting

import math
from weights.cognitive import on_access, decay, should_prune

def test_weight_after_access():
    w = on_access(0.5)
    assert math.isclose(w, 0.723, rel_tol=1e-3)

def test_decay_monotone():
    w = 0.7
    prev = w
    for h in range(1, 24):
        curr = decay(w, h)
        assert curr < prev
        prev = curr

def test_prune_threshold():
    assert should_prune(0.31, 100) is True
    assert should_prune(0.5, 0) is False
