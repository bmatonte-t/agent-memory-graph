# Pricing and Editions

## Purpose

Define a pragmatic commercial packaging baseline for marketplace submission and internal review.

## Proposed Editions

### Starter

Target audience:

- teams validating deterministic memory and auditability on a smaller workload.

Suggested scope:

- core MindMap pipeline,
- standard observability bundle,
- single environment support pattern.

### Enterprise

Target audience:

- production teams requiring stronger governance and operational controls.

Suggested scope:

- all Starter capabilities,
- advanced operational runbooks and support process alignment,
- enterprise rollout guidance and governance controls.

## Pricing Approach

Current recommendation is value-plus-usage:

- base platform charge by edition,
- variable cost aligned with actual infrastructure and model usage.

Primary usage drivers:

- Spanner capacity and query profile,
- Vertex model token usage,
- observability data volume,
- service runtime profile.
