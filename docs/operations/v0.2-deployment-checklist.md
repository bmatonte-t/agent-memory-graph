- [ ] Action counting implemented across all mutation paths

- [ ] Transient failures (ABORTED, RESOURCE_EXHAUSTED, DEADLINE_EXCEEDED) are retried

#### Phase 3: ABAC Authorization
- [ ] Empty `AuthorizationScope` correctly denied
- [ ] Multi-dimensional resource control enforced
- [ ] Authorization decisions logged with reason codes
- [ ] MCP dispatch enforces ABAC at entry point
- [ ] MemoryAPI operations enforce ABAC at access boundaries

- [ ] Evidence retrieval is tenant-safe
- [ ] Cross-tenant isolation verified with integration tests
- [ ] Graph-backed aggregation is default
- [ ] `get_evidence_context_for_tenant()` operational for diagnostics

## Rollback Plan (If Issues Detected)

**Automatic Rollback Trigger**: If ANY of the following occur:
- Error rate > 5% for 5 minutes
- Latency p95 > 10 seconds for 10 minutes
- Multiple authorization failures for same agent
- Database unavailability

**Manual Rollback Procedure**:

1. **Identify issue**:
   ```bash
   gcloud logging read "severity=ERROR" --limit 100
   ```

2. **Initiate rollback**:
   ```bash
   # Deploy previous stable version
   git checkout v0.1
   gcloud run deploy agent-memory-graph \
     --source . \
     --platform managed \
     --region us-central1
   ```

3. **Verify rollback**:
   - [ ] Service responding normally
   - [ ] Error rate returned to baseline
   - [ ] Latency normal

4. **Post-incident review**:
   - [ ] Root cause analysis
   - [ ] Fixes applied to codebase
   - [ ] Tests added to prevent regression
   - [ ] Re-deploy when ready

**Estimated Rollback Time**: 5-10 minutes
