## 1. Policy

| Rule | Requirement |
|------|------------|
| Coverage | Every dataset and corpus item used in the campaign must have an entry in this register before ingestion begins (E6-T1, E6-T2) |
| License verification | PVL and ML Lead must independently review all non-synthetic license terms before approving an entry |
| Attribution | CC-licensed datasets must be attributed in the final campaign report (E8-T3) |
| Modification disclosure | Share-alike licenses (CC BY-SA, CC BY-NC-SA) require disclosure if data is transformed; transformations are disclosed in the "Modification" column |
| Synthetic data | No license required; synthetic provenance is documented for audit reproducibility |
| Prohibited | No non-public or proprietary data; no datasets with a license that prohibits the campaign's use case |
